# public/assets · 素材来源与放置说明

> 这个目录下的 PNG **不进 Git 仓库**（见根目录 `.gitignore`），因为授权不允许公开再分发。
> 仓库只保存代码、地图与配置。

## 为什么

图块与角色来自 RPG Maker 系列素材（RPG Maker MZ RTP / ARPG plug-in set DLC / Avery 论坛附件）。
它们的授权只覆盖「RPG Maker 引擎 + 非商业私人使用」，且明确禁止再分发素材本体。
把 PNG 提交到公开仓库、或部署成公开网址，等于向所有人分发这些图片，属于越权使用。

站长已确认：本网站是个人自用、不商用。**如果要对外公开发布，素材必须换成
明确允许网页使用（any engine / web allowed）的原创或授权素材。**

## 生成 ground_grass.png 的方法

`outside_a5.png` 的第 5 列第 3 行（0 起算：col=4,row=2）是一块草地。
把它按不同像素偏移滚动 + 水平翻转，拼成 10 个变体、480×48 的一条，
用于让地面不出现整屏重复的斑点。脚本见交付说明，或按此规则重新生成。

## 谁生成的

  （它们会用 16px 占位图覆盖这里的正式素材）
