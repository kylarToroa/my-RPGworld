## 一、授权结论（依据 2026-06-22 版官方条款）

判定依据：Gotcha Gotcha Games 官方
[GGG Products Material Terms](https://rpgmakerofficial.com/en/support/rule/)（Update June 22, 2026）原文。

**关键条款摘录**

- Article 1 (Use)：
  > "Only users who have purchased the GGG Products in an authorized manner may use Our Material in the GGG Products
  > **for their programs other than the GGG Products and works created with gaming tools from other companies**."

  → 正版购买者可以把官方素材用于「RPG Maker 之外的程序」和「其他公司游戏工具创作的作品」。
  **跨引擎（含 Phaser / 自研 HTML5）在条款字面上是被允许的**，
  上一轮「官方 RTP 一律禁止跨引擎」的结论作废。

- 前置条件：必须是**通过官方渠道购买**的正版用户（同上 Article 1；主协议 Article 5）。非正版用户任何用法都不被授权。

- 商用：主协议 Article 1 明确「personal usage (including commercial usage)」适用本条款；
  公司/法人/团体需单独洽谈。当前项目是个人非商业站点，在允许范围内。

- 再分发：Material Terms Article 2 允许「免费转让给其他正版用户」以及「在博客、作品集中展示」，
  但**禁止向非正版用户分发素材本体**。

  这条决定了本项目的做法：
  - ✅ 可以把素材**嵌在游戏里**发布（那是"使用"，不是"分发素材"）；
  - ❌ 不能把 PNG 原文件放进公开仓库让人当素材下载。

- 署名义务（Distribution Article 2）：需要在成品中标注使用了 GGG 产品素材、
  附版权声明与商标声明。**当前项目尚未落实，见第五节。**

- 示例游戏素材有单独的禁止清单（Supplementary Provisions[Sample Games]）；
  官方 Add-On（DLC）不得脱离 User Software 独立分发（Add-on Article 3）。

### 归属判定的证据与限度

**已确认**：这些文件取自 `D:\ARPG-plugin-set\ARPG plug-in set\ARPG_SampleProject_en\img\`。
该目录下同时存在 **31 张 tilesets + 45 张 characters**，覆盖 Dungeon / World / Outside / Inside / SF_ 全系列，
并有 MZ 编辑器导出的图块标注文件（`Outside_A5.txt` 里是 "Meadow A|草地A" 这类条目）。
这与 RPG Maker MZ 标准 RTP 的完整构成一致；一个「插件集」DLC 不会附带整套 RTP。

**尚未验证**：本机**没有安装 RPG Maker MZ**，因此无法把 `Outside_A5.png` 与 MZ 安装目录下的原版 RTP 做字节级哈希比对。
所以上表的「MZ 自带 RTP」是**基于目录结构的强推断，不是哈希实证**。

→ **需要站长补充**：MZ 安装目录（通常在 `<RPG Maker MZ 安装路径>/img/tilesets/`）或 Steam 购买凭据。
补上之后可以跑一次哈希比对，把「强推断」升级为「已确认」，同时满足条款的「正版购买者」身份要求。

## 三、素材已纳入仓库（当前的取舍）

**代码要求的原文**：禁止向非正版用户分发素材本体。公开 GitHub 仓库 = 向任何人提供原文件下载，
严格来说不满足这一条。

**站长 2026-11-11 的决定**：这是一个个人非商业展示页，优先级是「能公开访问、能部署」，
因此选择把素材纳入版本管理，接受这一条授权瑕疵，版权问题以后再处理。

所以 `.gitignore` 不再排除 `public/assets/`：
13 张 PNG 已随仓库提交，`npm run build` 在任何机器上 clone 后即可直接通过，无需再跑同步脚本。

### 风险记录（如实写下，便于以后追溯）

- 这不是「有许可」，而是「个人非商业、实际几乎不会被追究」。
  真要被追究，条款上站不住脚。
- **一旦提交进 Git，历史里就留着了**（即使以后删除文件，旧提交仍能翻出来）。
  将来若要彻底清理，需要重写历史（`git filter-repo`），并注意已存在的 fork/clone。
- 缓解措施：`credit` 页面已按条款要求做了署名与版权声明（见第五节）。

### 以后的处理路径（三选一）

1. **换素材**：改用明确允许网页使用的素材（如 FreePixel 那种「个人+商用免费、无引擎限制」的），
   换完再清理历史。这是最干净的终局。
2. **补授权**：购买 RPG Maker MZ 正版并保留凭据。条款要求「正版购买者」，
   有凭据后再谈"跨引擎使用"才站得住。
3. **不管**：维持现状。个人站、非商业、无素材包二次分发意图。

### 同步方法（仍然有用）

```bash
# 方式一：环境变量（临时）
RPG_ASSET_RTP="<RPG Maker 素材 img 目录>" RPG_ASSET_LIBRARY="<素材库根目录>" npm run sync:assets

# 方式二：命令行参数
npm run sync:assets -- --rtp="<路径>" --library="<路径>"

# 方式三：本地配置文件（推荐，长期使用）
cp asset-library.example.json asset-library.local.json   # 然后填路径；该文件已被 .gitignore 忽略

# 只检查不写盘
npm run sync:assets -- --check
```

脚本只认 `assets.manifest.json` 里登记的文件，不做整目录搬运；
素材库原文件只读；任何一个源文件缺失都会整体失败，不会留下半套资源。

## 六、各文件的生成方式

| 文件 | 处理 |
|---|---|
| 8 张 RTP 图块 | 原样复制（保留索引色 PNG，不重编码） |
| `ground_grass.png` | 取 `Outside_A5` 的 (col=4,row=2) 草地格，按 10 组偏移环绕滚动 + 奇数位水平翻转，横向拼成 480×48 |
| `player/villager/librarian.png` | 从角色表裁出 144×192（4 向 × 3 帧） |
| `big_tree.png` | 从 `Outside_B` 裁出 96×96 |

以上全部由 `scripts/sync-assets.mjs` 完成，PNG 编解码在 `scripts/lib/png.mjs`（零依赖）。
