## Agent 是什么

可以粗略理解为：一个能**自己规划步骤、调用工具、检查结果**的语言模型程序。

1. 理解目标
2. 拆分步骤
3. 调用工具（搜索、写代码、读文件……）
4. 根据结果调整计划

## 我关心的问题

- 如何让 Agent 的每一步都**可验证**？
- 什么时候该让人类介入决策？
- 长任务中如何保持上下文不丢失？

> 好的工具不是替你思考，而是让你的思考走得更远。

```ts
// 代码块示例
function plan(goal: string): string[] {
  return ['理解', '拆分', '执行', '检查'].map((s) => `${s}: ${goal}`);
}
```
